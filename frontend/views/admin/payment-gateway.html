Webhook Endpoint

Register this URL in HitPay under Developers → Webhook Endpoints so payments are confirmed even if the parent closes the browser before returning.

{{ vm.gateway.webhookUrl }}

Note: HitPay refuses to accept a webhook on localhost, 127.0.0.1 or any private network address — it rejects the whole payment, not just the callback. When this API is running on such an address the webhook is therefore left out of the request automatically, and payments are confirmed when the parent is redirected back instead. That's enough to test the full flow locally. To have webhooks actually fire, put the API on a public URL (or a tunnel) and set API Base URL above to it.

Enter an API key above before enabling. ⚠️ Live mode charges real money.

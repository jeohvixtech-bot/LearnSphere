💰 Platform Fees

LearnSphere earns from two places at once, and they work in opposite directions. Keeping them separate is what stops one being mistaken for the other.

  • Markup is added on top of the tutor's base price. The parent pays it. The tutor never sees it and is never charged for it.
  • First match commission is taken out of the base price, once, on a match's first tuition period. The tutor pays it. Promotional credit exists to offset exactly this charge.
  • Recurring commission is a per-invoice cut of everything else. The launch model charges none — markup is the recurring revenue.

How a first match settles

Worked through at a {{ 100 | currency:'$' }} base price per session, four sessions, 15% markup and 100% first match commission:

  • Parent is invoiced {{ 460 | currency:'$' }} — {{ 400 | currency:'$' }} base plus {{ 60 | currency:'$' }} markup.
  • LearnSphere keeps the {{ 60 | currency:'$' }} markup.
  • The tutor is credited {{ 400 | currency:'$' }} and charged {{ 400 | currency:'$' }} first match commission — netting nothing.
  • If the tutor holds promotional credit, {{ 400 | currency:'$' }} of it is spent and the same amount returns to their withdrawable balance, so they take home {{ 400 | currency:'$' }} after all.
  • Every following month: the tutor receives the full {{ 400 | currency:'$' }} base and LearnSphere keeps only the markup.

Both sides of every charge appear on the tutor's statement, so a deduction is visible rather than silent. Nothing is ever edited — a reversal is always a new entry.
